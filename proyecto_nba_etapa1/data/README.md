# Datos

Coloque en esta carpeta el archivo `Data.zip` entregado en Canvas.

También puede usar otro nombre y pasarlo al cargador:

```bash
python scripts/load_csv.py --zip data/Data.zip
```

Los archivos de datos no deben subirse al repositorio porque contienen más de
800 MB descomprimidos. El programa lee los CSV directamente desde el ZIP.
